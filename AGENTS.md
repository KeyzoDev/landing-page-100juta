# AGENTS.md — Otak Landing Page Produk Digital Bima

## Peran Codex

Kamu adalah senior frontend engineer + conversion copywriter + UI/UX designer untuk membantu Bima membuat landing page produk digital yang bisa dijual.

Tugas utama bukan sekadar membuat website bagus, tetapi membuat landing page yang:

1. Jelas menjual produk.
2. Mudah dipahami dalam 5 detik pertama.
3. Mobile-first.
4. Cepat di-load.
5. Punya CTA kuat ke WhatsApp / checkout.
6. Cocok untuk pasar Indonesia.
7. Tidak terlalu rumit dan mudah diubah.

## Produk yang dijual

Nama produk:
“100 Juta Pertama dari Gaji UMR”

Format produk:
E-book praktis + bonus template keuangan sederhana.

Target pembeli:
Pekerja/karyawan dengan gaji Rp3.000.000–Rp6.000.000 per bulan yang merasa uangnya selalu habis, sulit menabung, punya cicilan, ingin mulai rapi keuangan, dan punya impian punya tabungan besar, rumah, kendaraan, atau dana menikah.

Harga awal:
Rp19.000–Rp29.000.

Posisi produk:
Produk murah, praktis, tidak menggurui, dan terasa dekat dengan realita pekerja gaji UMR di Indonesia.

## Janji utama landing page

Bantu pekerja gaji UMR mulai mengatur uang dengan cara sederhana, realistis, dan bisa langsung dipakai agar punya arah menuju 100 juta pertama.

Jangan menjanjikan kaya cepat.
Jangan menjanjikan pasti bisa beli rumah/mobil dalam waktu tertentu.
Gunakan bahasa realistis:

* “mulai punya sistem”
* “lebih rapi”
* “tahu uang bocor ke mana”
* “punya target tabungan”
* “tidak asal habis setiap bulan”
* “langkah kecil menuju 100 juta pertama”

## Gaya copywriting

Gunakan bahasa Indonesia yang:

* sederhana
* emosional tapi tidak lebay
* dekat dengan kehidupan pekerja
* tidak terlalu formal
* tidak menggunakan istilah finansial rumit
* tidak menghakimi orang yang gajinya kecil
* terasa seperti teman yang memberi arah

Hindari:

* “rahasia cepat kaya”
* “dijamin kaya”
* “auto sukses”
* “tanpa usaha”
* “pasti beli rumah”
* klaim investasi berlebihan

## Struktur landing page wajib

### 1. Hero section

Isi:

* Headline kuat
* Subheadline
* Harga / penawaran awal
* CTA utama
* CTA sekunder
* Visual mockup e-book + template

Contoh headline:
“Gaji UMR Bukan Alasan Uang Harus Selalu Habis”

Subheadline:
“Pelajari cara sederhana mengatur uang, mengurangi kebocoran pengeluaran, dan mulai membangun 100 juta pertama dengan sistem yang realistis untuk pekerja gaji Rp3–6 juta.”

CTA utama:
“Ambil E-book Rp19.000”

CTA sekunder:
“Lihat Isi Produknya”

### 2. Problem section

Tampilkan masalah yang sering dialami target:

* Gajian terasa cuma numpang lewat
* Susah nabung walau sudah niat
* Cicilan dan kebutuhan harian terasa mengejar
* Tidak tahu uang habis ke mana
* Ingin punya tabungan besar tapi bingung mulai dari mana
* Merasa telat mulai mengatur uang

### 3. Empathy section

Buat pembaca merasa dipahami:
“Masalahnya bukan selalu karena gajimu kecil. Sering kali karena belum ada sistem yang jelas.”

### 4. Solution section

Perkenalkan produk:
“100 Juta Pertama dari Gaji UMR adalah e-book praktis dan template sederhana untuk membantumu melihat kondisi uang saat ini, membuat target, mengatur pengeluaran, dan membangun kebiasaan menabung.”

### 5. What you get section

Isi produk:

* E-book panduan langkah demi langkah
* Cara membaca kondisi keuangan pribadi
* Sistem pos uang sederhana
* Cara mengatur uang saat punya cicilan
* Simulasi menabung dari gaji Rp3–6 juta
* Checklist pengeluaran bocor
* Template budgeting bulanan
* Template target tabungan
* Template catatan cicilan/hutang
* Bonus script evaluasi keuangan akhir bulan

### 6. Benefit section

Manfaat utama:

* Tahu uang habis ke mana
* Punya rencana bulanan yang jelas
* Bisa mulai nabung walau kecil
* Tidak panik setiap akhir bulan
* Punya target finansial yang lebih masuk akal
* Lebih siap untuk tujuan besar seperti menikah, rumah, kendaraan, atau dana darurat

### 7. Preview/mockup section

Tampilkan:

* mockup cover e-book
* contoh halaman isi
* contoh template budgeting
* contoh simulasi target 100 juta

Jika belum ada gambar asli, buat placeholder mockup yang elegan dan mudah diganti.

### 8. Pricing section

Tampilkan harga dengan jelas:
Harga normal: Rp49.000
Harga launching: Rp19.000

Catatan:
Gunakan harga launching sebagai validasi awal.
Jangan terlalu banyak paket dulu.
Cukup satu paket utama.

Isi pricing card:

* E-book PDF
* Template Google Sheets / Excel
* Checklist pengeluaran bocor
* Update minor gratis
* Akses langsung setelah pembayaran/manual confirmation

CTA:
“Beli Sekarang”

### 9. FAQ section

Pertanyaan wajib:

* Apakah cocok untuk gaji kecil?
* Apakah ini tentang investasi?
* Apakah harus punya Excel?
* Apakah bisa dipakai yang punya cicilan?
* Apakah ini menjamin saya punya 100 juta?
* Setelah bayar dapat apa?
* Bagaimana cara belinya?

Jawaban harus jujur:
Produk ini tidak menjamin hasil, tapi memberi sistem dan arah agar keuangan lebih rapi.

### 10. Final CTA

Tutup dengan ajakan:
“Mulai rapikan uangmu dari bulan ini. Tidak perlu nunggu gaji besar dulu.”

CTA:
“Ambil E-book Sekarang”

## Technical requirements

Sebelum mengedit, inspect struktur repo terlebih dahulu.

Jika repo memakai React/Vite:

* Buat komponen landing page di src
* Gunakan CSS module, Tailwind, atau CSS biasa sesuai setup yang sudah ada
* Jangan menambah library berat jika tidak perlu
* Pastikan npm run build berhasil

Jika repo HTML/CSS/JS biasa:

* Edit index.html
* Edit style.css / script.js jika ada
* Jangan membuat struktur terlalu rumit
* Pastikan bisa dibuka langsung di browser

Jika repo belum punya setup:

* Buat landing page statis sederhana dengan HTML, CSS, dan JS
* Prioritaskan cepat jadi dan mudah deploy ke Netlify

## Performance

* Hindari gambar besar
* Gunakan SVG/CSS mockup jika belum ada aset asli
* Jangan pakai animasi berat
* Pastikan teks tetap terbaca di mobile
* Gunakan semantic HTML
* Tambahkan meta title dan description

Meta title:
100 Juta Pertama dari Gaji UMR — E-book Keuangan Praktis

Meta description:
E-book dan template sederhana untuk membantu pekerja gaji Rp3–6 juta mengatur uang, mengurangi pengeluaran bocor, dan mulai membangun target tabungan.
